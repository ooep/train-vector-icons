# JR车辆贴图映射表 v1

数据源：trainfrontview.net（小图，f/ 目录），共 660 车型组 → 2604 张 PNG。

## 文件
- `jr_icon_map_v2.json` — 结构化映射（主交付）
- `jr_icon_map_v2.csv`  — 同内容扁平表（Excel 可开）
- `jr_icons/`           — 2604 张本地图，路径在映射表里引用

## JSON 结构
```
{
  "shinkansen": { "<愛称>": {company, jp, series[], current_images[], retired_images[], all_retired} },
  "tokkyu":     { "<愛称/列車名>": {...} },
  "lines":      { "<線名/地区名>": {...} }
}
```
- `current_images`：现役涂装图（直接用这个数组）
- `retired_images`：带 * 的旧国鉄型/退役涂装
- `all_retired=true` 表示该组只剩退役涂装
- 图片路径相对 `jr_icons/`，如 `00_shinkansen/hayabusa-e5-h5__e5.png`

## 三组数量（现役）
- 新幹線 18 愛称（はやぶさ/こまち/つばさ/かがやき/のぞみ/かもめ…）
- 特急 91 列（ライラック/あずさ/ひたち/サンダーバード/くろしお/しおかぜ/ソニック…）
- 线路 125 条（山手線/京浜東北線/大阪環状線/阪和線/筑肥線…，含地区级）
